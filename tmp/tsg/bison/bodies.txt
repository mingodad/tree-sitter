# Token bodies for the yacc dialect in bison.g, hand-written: bison.g is
# grammar-only (no Flex section), which is what the translator reports as
# "the lexer never returns STRING, TSTRING, BRACKETED_ID and 7 more".
ID            ([A-Za-z_][A-Za-z0-9_]*)
INT_LITERAL   ([0-9]+)
STRING        "([^"\\]|\\.)*"
TSTRING       '([^'\\]|\\.)*'
CHAR_LITERAL  '([^'\\]|\\.)'
BRACKETED_ID  \[[A-Za-z_][A-Za-z0-9_]*\]
TAG           <([A-Za-z_][A-Za-z0-9_.]*)?>
ACTION_CODE   \{[^{}]*\}
VERBATIN_CODE %\{[^\n]*%\}
SECTION_MARK  %%
ID_COLON      ([A-Za-z_][A-Za-z0-9_]* *:)
